## Ozgur answers (2026-09-15 ~16:19 UTC)

1. **Ground unit list vs ship names (Cat.2):** Under `Assaulting units:` / `Defending units:`, indented army names (`8th Indian Brigade`, `37th Division`) are **ground unit list items**. Ship name-only lines (`BB Haruna`, etc.) remain **ship names**. **Do not** treat army and ship as the same kind.

2. **Sweeping aircraft (Cat.3):** Lines such as `13 x A6M2 Zero sweeping at 15000 feet *` are **not** attached to a raid, air group, or named unit (fog of war: “could be from any of the units that has Zeros”). Store **type / count / altitude** only; **no** parent-block unit attribution.

3. **Ground combat structure (Cat.12):** Model each ground fight as **one parent `ground_combat` block** owning ordered child lines (header, attack type, forces, capture, modifiers, unit lists, etc.).

4. **Capture fact (Cat.12):** `Japanese forces CAPTURE … !!!` in combat reports is the **same capture fact** as in operations reports, with a **source** field (`operations`, `combat_report`, `combat_events`, …) so analytics do **not** double-count the same event across files.
